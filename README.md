# Online-Sales-Data

📌 PROJECT OVERVIEW

This project analyzes online sales data to understand sales performance, customer behavior, profit trends, and product insights.
The dashboard helps businesses make data-driven decisions using interactive visualizations and reports.

🎯 OBJECTIVE

Analyze overall sales performance
Identify top-selling products
Track profit and revenue trends
Understand customer purchasing behavior
Improve business decision-making using data insights
🛠️ TOOLS & TECHNOLOGIES USED
Power BI
Microsoft Excel
SQL
Python

📂 DATASET DETAILS

The dataset contains:

Order ID
Product Name
Category
Customer Name
Quantity
Sales Amount
Profit
Payment Mode
Order Date
Region

📊 DASHBOARD FEATURES

✅ SALES ANALYSIS
Total Sales
Monthly Sales Trends
Category-wise Sales

✅ PROFIT ANALYSIS
Total Profit
Profit by Product
Profit by Region

✅ CUSTOMER ANALYSIS
Customer Purchase Behavior
Top Customers
Customer Segmentation

✅ PRODUCT ANALYSIS
Best Selling Products
Product Performance
Quantity Sold

Identified top-performing products

Found customer buying patterns
Improved understanding of profit trends
